# RRFMCLI
RRFMCLI: Remus Rigo File Manager CLI, a Windows file utility for the command line (Delphi version)



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* `/UF` Update file: copy a source file over every file with the same name in a folder and its subfolders
* Lists every replaced file, and the total
* Native Win32 console app: no runtime needed
